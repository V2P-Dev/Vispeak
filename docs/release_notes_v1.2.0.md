## What's changed

**Added**
- **Equalizer Style**: Added a new setting with 4 distinct real-time visualization styles for the recording indicator:
  - **Spectrum**: Classic discrete bars with asymmetrical voice dynamics and idle breathing baseline.
  - **Spectrum Wave**: Smooth continuous harmonic traveling wave without baseline gaps.
  - **Neon Threads**: Elegant intertwined glowing ribbons with dynamic particle trace.
  - **Particles**: Fluid buoyant particle swarm reacting to voice volume.
- **Equalizer Style Selector**: Interactive picker in General Settings with responsive theme-aware preview cards for all 4 styles.
- **Split Orange Accent Preview**: 50/50 dark and light theme preview card for the Orange accent color in General Settings.

**Improved**
- **High-DPI Canvas Rendering**: Rendered visualizers on High-DPI Canvas with strict integer physical pixel grid snapping across all display scale factors (100%, 125%, 150%, 200%), eliminating subpixel blurring and uneven bar widths.
- **Theme & Accent Fidelity**: Full theme and accent color support (Orange / White / Black) for all visualizers in both Dark and Light themes.
- **Voice Responsiveness**: Increased sensitivity and dynamic amplitude response for Spectrum Wave and Neon Threads animations.
- **Bar Geometry & Spacing**: Calibrated uniform 2.0px bars and 4.0px gaps across Full, Compact, and At-Caret overlay skins.
