## What's changed
**Fixed**
- **Audio Ducking**: Fixed a bug where other applications' sound would remain muted (ducked) indefinitely if the dictation session encountered an error or a hardware timeout, or during a long transcription.
- **Audio Mute Timing**: Sound is now correctly restored immediately when the dictation recording phase finishes, without waiting for the transcription process to complete.

**Changed**
- **Audio Cue Volume**: reduced peak volume of sound cues (start/stop beep signals) from 0.5 to 0.2 for a more comfortable listening experience.
