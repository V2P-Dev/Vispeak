## What's changed
**Added**
- **Accent Color Customization**: choose between 3 brand accent color options (`Orange` / default, `White`, `Black`) in Settings -> General (`accent_color`), applied dynamically via `data-accent` attributes.
- **Reactive Theme Contrast Warnings**: automatic UI alerts when selecting high-risk accent and theme combinations (White accent on Light theme, Black accent on Dark theme).

**Improved**
- **Universal Label & Badge Contrast**: refactored card selection titles, option labels, tabs, and status banners across all pages to use static primary/semantic text tokens (`text-primary`, `text-error`, `text-success`), guaranteeing 100% legibility in any theme and accent color combination.
- **Overlay Glow Styling**: updated recording state glow and equalizer styling to adapt seamlessly to the selected accent color while preserving isolated processing/success/error semantic states.
