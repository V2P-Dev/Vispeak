# Vispeak

Vispeak — приложение для диктовки на Windows и Linux. Нажмите глобальную горячую клавишу, произнесите текст — приложение распознает речь локально и вставит результат в активное поле ввода.

Читать на: [English](README.md) | Русский

## Особенности
- 🎙️ **Полностью офлайн**: Аудио не отправляется на сторонние серверы, всё обрабатывается локально на вашем компьютере с помощью Whisper, Parakeet, Canary, GigaAM, Nemotron или Qwen3-ASR.
- ⚡ **Глобальный хоткей**: Нажмите `Ctrl+Space` (по умолчанию) в любом приложении, произнесите текст, отпустите клавишу — и текст будет вставлен.
- 🎨 **Настраиваемый оверлей**: Полный, компактный и мини-виджет, стили спектра и цветовой акцент.
- 📝 **История и управление**: Локальная история, повторное распознавание, режим удержания или переключения записи, отмена и приглушение других приложений.
- 🖥️ **Windows и Linux**: Интеграция X11 и Wayland; на Wayland горячие клавиши и вставка требуют системных разрешений.
- 📦 **Модели на выбор**: Используйте легкие модели для скорости или более крупные для точности распознавания. Все модели загружаются отдельно от приложения по запросу пользователя.

## 🤖 Распознавание речи (Модели)
Приложение поддерживает различные модели для транскрибации. **Они не входят в состав приложения и скачиваются автоматически с Hugging Face только по вашему явному запросу в настройках.**

| Семейство моделей | Лицензия | Источник (Hugging Face) | Описание |
|-------------------|----------|-------------------------|----------|
| **Whisper** | MIT | `ggerganov/whisper.cpp` | Базовые модели от OpenAI (через whisper.cpp) |
| **Parakeet TDT / Canary v2** | CC-BY-4.0 | `istupakov/...` | Модели от NVIDIA с высокой точностью |
| **GigaAM v3** | MIT | `istupakov/gigaam-v3-onnx` | Распознавание русской речи (SberDevices) |
| **Nemotron 3.5 / Qwen3-ASR** | Разные | `handy-computer/...` | Модели в формате GGUF |

Подробную информацию о лицензиях и источниках моделей см. в [THIRD_PARTY_LICENSES.md](./THIRD_PARTY_LICENSES.md).

## 🔒 Конфиденциальность (Privacy)
- **Локальная обработка**: Всё распознавание речи выполняется исключительно локально на вашем устройстве. Аудио и распознанный текст никогда не отправляются ни на какие серверы.
- **Локальная история**: История диктовок хранится локально в `%LOCALAPPDATA%/app.vispeak` на Windows и `~/.local/share/app.vispeak` на Linux (или `$XDG_DATA_HOME/app.vispeak`) и полностью управляется пользователем (можно настроить лимит хранения или полностью очистить).
- **Сетевые обращения**: Приложение выполняет только два вида сетевых запросов: проверка и скачивание обновлений (GitHub Releases) и скачивание моделей с Hugging Face (только по явному действию пользователя). Телеметрия и аналитика полностью отсутствуют.

## Установка

Готовые сборки доступны в [последнем релизе](https://github.com/V2P-Dev/Vispeak/releases/latest), раздел **Assets**. Все сборки — x86_64.

### Windows 10/11

1. Скачайте `Vispeak_<версия>_x64-setup.exe` и запустите установщик. Альтернатива — `.msi`.
2. Откройте Vispeak через меню «Пуск»; настройки также доступны через значок в трее.
3. Уже установленные Windows-версии проверяют обновления при запуске и каждые пять часов. Для проверки сразу используйте раздел обновлений в настройках и подтвердите установку предложенной версии. Файлы `.sig` и `latest.json` скачивать вручную не нужно.

### Ubuntu 24.04+ / Debian 13+

Скачайте `.deb` с названием вашего дистрибутива. В папке загрузки выполните одну подходящую команду:

```bash
# Ubuntu
sudo apt install ./*ubuntu*.deb
# Debian
sudo apt install ./*debian*.deb
```

### Fedora 44

Скачайте Fedora `.rpm`, затем в папке загрузки:

```bash
sudo dnf install ./*fedora*.rpm
```

### Arch Linux

Установите инструменты сборки и обновите систему:

```bash
sudo pacman -Syu --needed base-devel git
```

Скачайте `v<версия>-arch-PKGBUILD` из Assets, поместите его в отдельную папку, переименуйте в `PKGBUILD`, просмотрите рецепт и выполните **без sudo**:

```bash
makepkg -si
```

Рецепт собирает текущие исходники ветки `main` и устанавливает `vispeak-git`; в AUR он не опубликован. Готовый Arch-архив `.tar.gz` также доступен для ручной установки; зависимости и сборка описаны в [руководстве Linux](docs/LINUX.md).

### Первый запуск на Linux

Запустите **Vispeak** из меню приложений или командой `vispeak`. На Wayland подтвердите запросы порталов для горячих клавиш и управления клавиатурой. В «Управлении» проверьте назначенное системой сочетание; при необходимости нажмите «Настроить горячие клавиши в системе».

Нужен `xdg-desktop-portal` и backend вашего окружения с GlobalShortcuts и RemoteDesktop, например KDE. На X11 используются `xdotool` и `xclip`. В GNOME для значка трея может понадобиться расширение AppIndicator. Linux обновляется установкой нового пакета, встроенное Windows-обновление к нему не применяется.

**Пользовательское тестирование v1.3.0 ограничено Fedora Linux 44 KDE Plasma Desktop Edition, Plasma 6.7.5 / KWin 6.7.5, Wayland.** Сборки других систем не означают проверку работы на них. Скругление оверлея в обработке/результате и визуальное положение у каретки ещё требуют подтверждения. Остальные зависимости и ограничения — в [руководстве Linux](docs/LINUX.md).

## Начало работы

1. В настройках откройте **Модель**, скачайте модель и нажмите **Выбрать**. Для скачивания нужен интернет; дальнейшее распознавание работает офлайн.
2. Откройте текстовый редактор, браузер или мессенджер и поставьте курсор в поле ввода.
3. В режиме удержания нажмите и держите `Ctrl+Space` (или назначенный системой хоткей), произнесите текст и отпустите клавиши. В режиме переключения нажмите сочетание повторно для остановки.
4. Готовый текст вставится в активное поле. `Esc` отменяет запись, если это сочетание назначено; на Wayland портал может запросить дополнительное подтверждение.

На Wayland используется вставка готового результата: потоковый посимвольный ввод отключён. Хоткей должен содержать обычную клавишу; отдельный правый/левый Ctrl, Alt или Shift портал не различает.

## Сборка из исходников

Для Windows нужны Rust stable, Node.js 22+, LLVM и MSVC Build Tools. Для Linux системные зависимости и настройка dev-запуска приведены в [руководстве Linux](docs/LINUX.md).

```bash
git clone https://github.com/V2P-Dev/Vispeak.git
cd Vispeak
npm ci
npm run tauri dev
```

Релизная сборка: `npm run tauri build` на Windows, `npm run build:linux -- --bundles deb,rpm -- --locked` на Linux.
